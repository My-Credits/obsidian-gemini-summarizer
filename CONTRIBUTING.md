# Contributing to Gemini Universal Summarizer

This is my first open-source project and I am still learning web development and Python.
Contributions, bug fixes, pull requests, and code refactorings are warmly welcomed!

## How to Contribute
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/improvement`).
3. Make your changes to `main.ts` or `main.js`.
4. Submit a Pull Request.
